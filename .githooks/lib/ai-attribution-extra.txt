# Project-owned additions to the PromptKit AI-attribution detector.
#
# WHY THIS EXISTS
# PROMPTKIT.md declares `ai-attribution: off`, which makes the engine checker
# enforce instead of skip. But the engine ruleset
# (.promptkit/scripts/ai-attribution-patterns.txt) names Claude, Copilot, Cursor,
# Codex and a generic "AI Assistant" identity — it does NOT name Codebuff, which
# is the agent that actually commits in this repository. Without these rows the
# policy would be decorative for the one signature it most needs to catch.
#
# HOW IT LOADS
# Through PROMPTKIT_AI_ATTRIBUTION_RULES_EXTRA, the seam the engine documents for
# project additions. Never edit the engine copy: .promptkit is a pinned submodule
# and any edit inside it is lost on reinstall and diverges from the pinned
# revision.
#
# FORMAT
# RULE|regex|tier, POSIX ERE and .NET compatible: no [[:space:]] classes, no \s,
# no alternation (a `|` would collide with the field separator), no non-ASCII.
#
# ANCHORING
# Co-author rows are anchored to the start of a line, matching the engine's
# convention, so ordinary prose discussing the tool does not match. The
# generated-with rows are deliberately NOT anchored: the real-world footer is
# `🤖 Generated with Codebuff`, whose first character is a non-ASCII emoji that
# this format cannot express. Anchoring those rows would miss the exact footer
# this policy exists to prevent.
COAUTHORED_AI_CODEBUFF|^[Cc]o-[Aa]uthored-[Bb]y:.*[Cc]odebuff|trailer
COAUTHORED_AI_FREEBUFF|^[Cc]o-[Aa]uthored-[Bb]y:.*[Ff]reebuff|trailer
GENERATED_WITH_CODEBUFF|Generated with .*[Cc]odebuff|footer
GENERATED_WITH_FREEBUFF|Generated with .*[Ff]reebuff|footer
GENERATED_BY_FREEBUFF|Generated by .*[Ff]reebuff|footer
