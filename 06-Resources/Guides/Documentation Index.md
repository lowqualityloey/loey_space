# Documentation Index

This index groups the vault guides by what you want to accomplish. All links use standard relative Markdown paths so they work both on GitHub and inside Obsidian.

## Setup and Installation

- [Setup & Configuration](Setup%20&%20Configuration.md): Complete setup checklist, pre-configured repository settings, required in-app Templater and QuickAdd setup, and bundled plugin rules.
- [Mobile Workflow Guide](Mobile%20Workflow%20Guide.md): Fast capture on phone and batch processing on desktop.

## Daily Use and Organization

- [Second Brain Guide](Second%20Brain%20Guide.md): Daily note routines, folder structure, task lifecycle, Kanban board lanes, and concept note connections.
- [QuickAdd Inbox Optimization Guide](QuickAdd%20Inbox%20Optimization%20Guide.md): How rapid capture works, the inbox dump file, and optional template capture choices.
- [Hey Loey Guide](Hey%20Loey%20Guide.md): Conversational commands (`"hey loey"`), daily routines, autonomous milestone logging, and the distinction between chat prompts and the CLI tool.

## Reviews and Analytics

- [Weekly AI Summary Guide](Weekly%20AI%20Summary%20Guide.md): Generating seven-day reviews, metrics extraction, the two review creation paths, and details on what data is sent to Google Gemini.
- [Habit Analytics Dashboard](../../07-Reviews/Habit%20Analytics%20Dashboard.md): Rolling 30-day habit completion rates, heatmaps, and streak trends.

## Maintenance and System Health

- [Maintenance & Troubleshooting](Maintenance%20&%20Troubleshooting.md): Solutions for common errors, plugin update recovery, and a clear list of read-only verification checks versus mutating commands.
- [Vault Security Policy](Vault%20Security%20Policy.md): Storage rules for sensitive information, `.gitignore` boundaries, and the pre-commit secret scanner.
- [Tagging & Properties](Tagging%20&%20Properties.md): The frontmatter schema, required properties by note type, and tag naming conventions.
- [Plugin Ownership](Plugin%20Ownership.md): Provenance of custom-built plugins (`homepulse` and `kanban-status-sync`) and instructions for reapplying patches after updates.
- [CONTRIBUTING](CONTRIBUTING.md): Scope for public contributions, test mocking in Node without Obsidian, and pull request guidelines.

## Technical Records

- [TypeScript Migration Feasibility Assessment](TypeScript%20Migration%20Feasibility%20Assessment.md): Architectural evaluation of the TypeScript build pipeline for automation scripts.
- `docs/`: Local engineering specifications, architectural decision records (ADRs), task records, and verification logs (git-ignored on the public branch).
